# 🍔 Foodie Hub

A food delivery web application built with React.js, featuring restaurant browsing, live API integration, search, routing, cart management, and a responsive user interface.

## 🚀 Features

* 🍽️ Browse restaurants and food items
* 🔗 Integrated **live API data** and fetched restaurant/menu information dynamically
* 🔍 Search and filter restaurants
* 🛒 Add and manage items in the cart
* 🧭 Client-side routing with React Router
* ⚛️ Reusable React components
* 🪝 React Hooks — `useState`, `useEffect`, `useContext`
* 🗂️ Redux Toolkit for cart state management
* ⏳ Shimmer UI for loading states
* 🌐 Online/offline status detection
* 🧪 Testing with Jest & React Testing Library

## 🛠️ Tech Stack

Frontend: React.js, JavaScript, HTML, CSS
State Management: Redux Toolkit, Context API
Routing: React Router
API: REST API integration & asynchronous data fetching
Build Tool: Parcel
Testing: Jest, React Testing Library
Tools: Git, GitHub, VS Code

## 📡 API Integration

The application is connected to a **live API** to fetch restaurant and menu data dynamically.
